## 📦 Projetos em Destaque

### [json-pdf-designer](https://github.com/williamanjo/json-pdf-designer) — [▶ playground](https://williamanjo.github.io/json-pdf-designer/playground/)
> Editor visual de relatórios PDF para React: arrasta o campo na página, vincula a uma chave do JSON, gera o PDF. O template é **um objeto JSON serializável**, e a geração é JavaScript puro sobre pdf-lib — o mesmo código roda no navegador, numa API Node ou num worker de fila.

[![npm version](https://img.shields.io/npm/v/json-pdf-designer?style=flat-square&color=CB3837)](https://www.npmjs.com/package/json-pdf-designer)
[![npm downloads](https://img.shields.io/npm/dm/json-pdf-designer?style=flat-square&color=CB3837)](https://www.npmjs.com/package/json-pdf-designer)
[![docs](https://img.shields.io/badge/docs-website-blue?style=flat-square)](https://williamanjo.github.io/json-pdf-designer/)
[![license MIT](https://img.shields.io/badge/license-MIT-green?style=flat-square)](https://github.com/williamanjo/json-pdf-designer/blob/main/LICENSE)

Paginação real, seções mestre-detalhe, tabelas com colunas calculadas, gráficos, cartões de KPI e fundo de papel timbrado. 1.129 testes automatizados, TypeScript com tipos inclusos, ESM + CJS, e 3 dependências de runtime — os 5 peers são todos opcionais.
